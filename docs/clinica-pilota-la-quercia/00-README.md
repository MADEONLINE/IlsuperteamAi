# Clinica pilota fittizia · Clinica Veterinaria La Quercia

Dossier completo di una **clinica veterinaria media di paese del Nord Italia**, interamente inventata ma calibrata sul mercato italiano 2025-2026, da usare come conoscenza di progetto per istruire un sistema agentico di marketing su Claude Cowork.

Caratteristiche del modello: cani e gatti, nessun servizio H24 né reperibilità notturna, 5 veterinari (di cui 1 consulente), 9 persone in totale, € 835.000 di fatturato, comune fittizio di 14.200 abitanti nella pedemontana trevigiana, reputazione buona ma presenza digitale di media performance.

## Come usarlo

1. Carica i file 01-07 come conoscenza di un progetto Cowork.
2. Incolla la sezione 2 del file 08 nelle istruzioni di progetto.
3. Testa con i prompt della sezione 6 del file 08.
4. Quando passi alla clinica reale, rispondi al file 09 e fai riscrivere i file 01-07 con i dati veri.

## Avvertenze

- Tutti i nomi (clinica, persone, comune, competitor, strutture H24) e i recapiti sono inventati. Il prefisso 0423 è reale per l'area, i numeri con "555" segnalano la finzione.
- I prezzi sono verosimili per il Nord-Est ma non costituiscono un riferimento tariffario.
- Le indicazioni di conformità (Codice Deontologico FNOVI, GDPR) sono orientative: vanno verificate con il direttore sanitario e con un consulente prima dell'uso reale.
